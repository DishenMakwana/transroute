# Memory — Architecture

## Architecture Overview
- **Framework**: Next.js 16 (App Router) with React 19.
- **Styling**: Tailwind CSS v4 + Framer Motion animations.
- **Icons**: Lucide React library.
- **Database**: PostgreSQL (via `@neondatabase/serverless` and standard `pg`) managed with Drizzle ORM.
- **In-Memory Fallback**: Zero-config deep-cloned seed data storage for local/offline execution.
- **Charts**: Recharts 2.x for logistics tariff analytics and state volume spreads.
- **Exporting**: XLSX library for `.xlsx` rate matrix generation.
