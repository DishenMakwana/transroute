# Memory — Project Dependencies

## Runtime Dependencies
- `next`: React application framework (App Router).
- `react`, `react-dom`: UI rendering engine (React 19).
- `drizzle-orm`: TypeScript ORM for PostgreSQL.
- `@neondatabase/serverless`, `pg`: PostgreSQL client connectors.
- `framer-motion`: Motion and modal animation primitives.
- `lucide-react`: Standard icon library (replaces static text emojis).
- `recharts`: SVG charting library.
- `react-hot-toast`: Notification toast library.
- `xlsx`: Excel spreadsheet parser and generator.
- `tailwindcss`: Utility-first CSS styling engine.

## Dev Dependencies
- `eslint@^9`, `eslint-config-next@16.4.2`: Code linting.
- `prettier@^3.9.10`: Code formatting.
- `knip@^5`: Dead-code and unused export auditing.
- `drizzle-kit`: Migration and database schema tool.
- `typescript`: Strict type analysis.
