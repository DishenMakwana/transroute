# Memory — Project Overview

## Project Name
**TransRoute** — Domestic LTL Parcel & Carton Dispatch Directory in India.

## Core Problem & Value Proposition
Standard road freight logistics in India is fragmented. TransRoute provides a fast, specialized directory for business-to-business product box and carton dispatch, featuring:
- Corridor rate discovery (Per Kg, Small Box, Medium Box, Large Carton, CFT, CBM).
- Godown and booking office directory with live IST operational status.
- PIN code and multi-city route search.
- Interactive rate analytics dashboard.
- Excel rate card export.
